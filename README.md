# Phishing Website Detection — FilteredClassifier & InfoGain Benchmark

A leak-free `scikit-learn` pipeline implementation of the WEKA `FilteredClassifier` architecture evaluated on the UCI Phishing Websites Dataset (Dataset ID 327: 11,055 instances, 30 URL and DOM attributes). This repository benchmarks baseline C4.5/J48 decision trees against 50% Information Gain (`SelectKBest` with discrete mutual information) dimensionality reduction.

---

## Evaluated Pipelines

1. **`FC_Default_J48`**: Identity pass-through filter paired with an entropy-based pruned Decision Tree (`ccp_alpha=0.001`), replicating WEKA's default `FilteredClassifier` + `J48` setup on pre-discretized `{-1, 0, 1}` attributes.
2. **`FC_InfoGain15_J48`**: `SelectKBest` (`mutual_info_classif` with `discrete_features=True`, $k=15$) paired with a J48-equivalent Decision Tree.
3. **`FC_InfoGain15_RF`**: `SelectKBest` (`mutual_info_classif` with `discrete_features=True`, $k=15$) paired with a 100-tree Random Forest classifier.

---

## Benchmark Results

| **`FC_InfoGain15_J48`** | 93.75 | 0.8734 | 94.21 | 95.02 | 94.56 | 94.79 | 0.8828 | 0.0054 |
| **`FC_InfoGain15_RF`** | **96.35** | **0.9260** | **96.79** | **96.55** | **97.73** | **97.13** | **0.9349** | 0.1133 |
